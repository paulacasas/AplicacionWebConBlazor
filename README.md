# 🌌 Aplicación Blazor - Rick and Morty API

Este proyecto es una aplicación web desarrollada con **Blazor WebAssembly** que consume la **API pública de Rick and Morty** para mostrar información sobre los personajes de la serie.

---

## 🚀 Tecnologías utilizadas
- **.NET 8**
- **Blazor WebAssembly**
- **C#**
- **JSON / HttpClient**
- **Rick and Morty API** → [https://rickandmortyapi.com/](https://rickandmortyapi.com/)

---

## ⚙️ Descripción general
La aplicación se conecta a la API de Rick and Morty y muestra una lista de personajes con su nombre, especie, género, estado y una imagen.

Se implementan los modelos:
- **Character**: representa un personaje individual.
- **Characters**: representa la respuesta general de la API (lista de personajes + info de paginación).
